# AI Tooling

## Preferred MCP Tools
- `context7`: official library docs and API references
- `ddg-search`: current research and validation
- `grep_searchGitHub`: real-world usage patterns
- `sequentialthinking`: complex reasoning breakdown
- `playwright`: browser automation and UI checks

## Prompting
- Include context (`@file`), constraints, acceptance criteria, and examples
- Request explicit output format
- Iterate with focused feedback

## Library Recommendation Workflow
- Prefer battle-tested options first
- Verify latest stable versions via official docs/registries/release notes
- Use MCP (`context7`, `ddg-search`) to validate recency and fit
- Avoid custom builds when established tools solve the problem
- If not choosing latest stable, document the pragmatic reason
