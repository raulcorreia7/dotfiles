# /docs

Maintain human-first documentation.

---

## Purpose

Keep product knowledge current, linked, and actionable.

## Scope

- ✅ Knowledge bases, guides, FAQs, runbooks
- ❌ Specifications, ADRs, contracts (flag for escalation)

## Process

1. **Survey** — Inventory docs; note freshness and drift
2. **Prioritize** — Rank by user impact
3. **Revise** — Update, link, remove stale content
4. **Plan** — Cadence for keeping docs aligned

## Principles

- Prioritize freshness over completeness
- Remove redundant/stale content
- Optimize for humans and LLMs
- Minimal footprint: smallest viable doc set

## Output

- Summary: what was reviewed/updated/removed
- Completed actions: per file with links
- Next steps: owner + due date
