# GLOSSARY.md Format

`GLOSSARY.md` is the canonical vocabulary for the teaching workspace. Add terms only after the user understands them well enough to use them correctly.

## Template

```md
# {Topic} Glossary

{One or two sentences describing the topic the glossary covers.}

## Terms

**Term**: Tight definition in one or two sentences.
_Avoid_: weaker alias, ambiguous wording

**Term**: Tight definition in one or two sentences.
_Avoid_: weaker alias, ambiguous wording
```

## Rules

- Do not use the glossary as a dumping-ground dictionary.
- Pick canonical terms and list aliases to avoid when that reduces ambiguity.
- Keep definitions tight: define what the term is, not every use.
- Prefer glossary terms inside later definitions once they exist.
- Group terms under subheadings when natural clusters emerge.
- Flag field ambiguity and state the workspace's chosen meaning.
- Revise stale definitions in place as understanding deepens.
