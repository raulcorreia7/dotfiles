# RESOURCES.md Format

`RESOURCES.md` is the curated source list for the teaching workspace. Use it for knowledge sources and communities instead of unsupported recall.

## Template

```md
# {Topic} Resources

## Knowledge

- [Book: _Title_ -- Author](https://example.com)
  What it covers. Use for: specific cases where this source is strongest.
- [Article: "Title" -- Author](https://example.com)
  What it covers. Use for: specific cases where this source is strongest.

## Wisdom (Communities)

- [Community name](https://example.com)
  Why it is high-signal. Use for: feedback, critique, or real-world practice.

## Gaps

- {Missing source area needed by the mission}
```

## Rules

- Prefer primary sources, recognized experts, peer-reviewed work, and strongly moderated communities.
- Annotate every entry with what it covers and when to use it.
- Group sources as Knowledge or Wisdom.
- Record source gaps explicitly.
- Remove sources that prove shallow, wrong, or off-mission.
- Record community preferences, including when the user opts out.
