# Documentation Diagrams

Use `$diagrams` and `../../../references/diagrams/diagrams.md` for shared Mermaid syntax, supported diagram types, Azure DevOps compatibility, edge labels, and visual quality.

## Docs Placement

- Put a small visual overview after the TL;DR only when it compresses orientation or makes the reader safer/faster.
- Put flow, sequence, state, data, dependency, or class diagrams next to the section they explain.
- Put large architecture maps, exhaustive dependency graphs, or reference-only diagrams in appendix/reference.
- Link to the source-backed facts that justify the diagram when drift is likely.
